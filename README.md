# CodeAlpha Python Internship Projects

This repository contains two Python projects completed as part of my CodeAlpha Internship.

## Task 1: Hangman Game

A simple word-guessing game developed using Python.

### Features
- Random word selection
- Six chances to guess the word
- Correct and incorrect guess tracking
- Option to play again

### How to Run
```bash
python hangman.py
```

## Task 2: Basic Chatbot

A simple rule-based chatbot developed using Python.

### Features
- Responds to greetings
- Answers simple questions
- Provides basic information about Python
- Exits when the user types "bye"

### How to Run
```bash
python chatbot.py
```
